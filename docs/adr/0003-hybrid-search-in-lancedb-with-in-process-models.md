# Hybrid search in LanceDB, with embedding and re-ranking models run in-process

Search combines BM25 keyword search and dense embeddings, fused with reciprocal rank fusion and then re-ranked by a local cross-encoder, because on the project's own QASPER measurements re-ranking was the largest single gain and the fused top 30 already held almost all the evidence. The index lives in LanceDB, which does keyword, vector and fused search embedded on the laptop; Chroma, the usual default, was rejected because its local mode cannot do keyword or fused search. The embedding and re-ranking models (bge-small-en-v1.5 and gte-reranker-modernbert-base to start) run inside the project's own Python environment through sentence-transformers rather than through Ollama, which has no re-ranking endpoint, so nothing is installed machine-wide and the models cost no quota.
