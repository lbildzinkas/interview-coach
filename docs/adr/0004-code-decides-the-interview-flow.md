# Plain code decides the interview flow; the model only words questions and grades

Interview mode is a bounded LangGraph cycle in which a plain Python policy decides whether to probe, hint, move on or stop, from the grader's structured yes-or-no verdicts and counters kept in state; the model only phrases the next question and grades answers. We chose this over letting the model run the interview because the decisions become unit-testable without a model, cheap, and bounded (the default LangGraph recursion limit is about 10,000 steps, so a model-driven loop could burn thousands of plan calls), and because tool-selection errors concentrate where models make multi-turn choices. The same idea applies at the graph entry: slash commands pick the mode, and free-text routing (GLM, Jev or a local classifier) is added only as a measured comparison.
