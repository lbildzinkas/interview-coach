# Personal data and third-party study material stay out of the repository

The repository is public, so the candidate's transcripts, STAR stories, CV and grades on real answers are kept in local, git-ignored files and never committed. Third-party study material is downloaded at setup from a sources list (with a third-party notices file for attribution) instead of being copied in, because some sources only allow personal use. The project's own evaluation questions, and grading labels made on synthetic answers, are committed.
